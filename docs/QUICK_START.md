# Быстрый старт (Quick Start)

Этот раздел описывает, как развернуть проект локально и запустить дашборд за 10 минут.

## 1. Минимальные требования

- **Node.js** версии 20.0.0 или новее (для пайплайна сборки данных и локального сервера)
- **Браузер** с поддержкой IndexedDB (все современные Chrome, Firefox, Edge, Safari ≥ 14)
- **Git** (для клонирования репозитория; опционально, если проект скачан как zip)

> ⚠️ **Python 3.x** также подойдёт для запуска локального сервера (если не хотите устанавливать Node.js-зависимости).

---

## 2. Установка и локальный запуск

### Вариант А: через Node.js (рекомендуется)

```cmd
:: Клонируйте репозиторий (или распакуйте zip):
git clone https://github.com/<your-username>/faucetpay-dashboard.git
cd faucetpay-dashboard

:: Установите зависимости (@libsql/client для работы с Turso):
npm install

:: Запустите локальный веб-сервер на порту 3000 (использует npx serve):
npm run start
```

### Вариант Б: через встроенный HTTP-сервер Python (без npm)

Если Node.js не установлен, но есть Python 3:

```cmd
cd faucetpay-dashboard
python -m http.server 8000
```

---

## 3. Открытие в браузере

Откройте в браузере:

| Вариант запуска | URL |
|-----------------|-----|
| `npm run start` (npx serve) | **http://localhost:3000** |
| Python `http.server` | **http://localhost:8000** |

---

## 4. ❗ Важно: почему нельзя просто открыть index.html двойным кликом

**Ни при каких обстоятельствах не открывайте `index.html` напрямую как `file:///...`.**

Браузеры блокируют для протокола `file://`:
1. **`fetch()`-запросы** к Turso БД и к локальному `faucets.json` — таблица останется пустой.
2. **IndexedDB** (кэш `snapshots`) — может либо не работать, либо работать некорректно.
3. **CORS-политику** к сторонним API.

Всегда запускайте **локальный веб-сервер** (любой из двух способов выше).

---

## 5. Опубликованная версия (GitHub Pages)

Проект разворачивается на GitHub Pages автоматически после каждого коммита в `main`. URL для доступа:

```
https://<your-username>.github.io/faucetpay-dashboard/
```

> Если в настройках репозитория задан Custom Domain — используйте его. Первую загрузку всегда делайте с очисткой кэша браузера (Ctrl+F5 / Cmd+Shift+R).

---

## 6. Первый вход в админпанель

1. Нажмите кнопку **«⚙️ Админпанель»** в правом верхнем углу главной страницы.
2. **Шаг 1 (Пароль UI):** введите пароль по умолчанию `admin123` (если не изменён в `auth_config.js`).
3. **Шаг 2 (Токен Turso Full-Access):** введите WRITE-READ токен из локального файла `Turso_DB_Connection.md` или GitHub Secrets `TURSO_TOKEN`.

> 🔐 **Помните**: WRITE-READ токен хранится **только** в `sessionStorage` (вкладка браузера). Никогда не сохраняйте его в `localStorage`, в заметки или в переписку. По умолчанию сессия истекает через 24 часа.

---

## 7. Что делать, если таблица пустая (0 записей)

1. Нажмите кнопку **«⟳ Полное обновление»** (сбрасывает IndexedDB-кэш).
2. Если не помогло — откройте **GitHub Actions** и убедитесь, что последний запуск пайплайна `Fetch Faucets` завершился зеленым (статус `✅ success`).
3. Проверьте в настройках репозитория наличие секретов `TURSO_URL` и `TURSO_TOKEN`.

Дополнительные решения — в разделе [Разработка и отладка](DEVELOPMENT.md#83-частые-проблемы-и-их-решения-faqtroubleshooting).
