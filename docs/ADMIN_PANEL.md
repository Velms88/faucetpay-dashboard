# Админпанель

Панель ручной модерации кранов. Используется модераторами и девелоперами.

---

## 1. Вход в админпанель (2 шага, 2FA)

1. На главной странице нажмите кнопку **`⚙️ Админпанель`**.
2. Откроется модальное окно с двумя полями:

| Поле | Назначение | По умолчанию |
|------|-----------|:-----------:|
| **🔐 Пароль панели** | Пароль UI-уровня. Защищает открытие интерфейса админки. Не даёт прав на запись в БД! | `admin123` |
| **🔑 Turso Admin Key (Full-Access)** | **WRITE-READ** JWT-токен Turso (`TURSO_TOKEN`). С этим токеном браузер получает право делать `UPDATE` в таблицах `targets_moderation` и `config`. | ⚠️ **НЕТ ЗНАЧЕНИЯ ПО УМОЛЧАНИЮ — вводится вручную каждый раз.** |

### Где взять Turso Admin Key:
- Локально — из файла **`Turso_DB_Connection.md`** (лежит в корне проекта; НЕ КОММИТИТСЯ!).
- В репозитории — из GitHub Secrets → **`TURSO_TOKEN`**.

## 2. Управление сессией

| Параметр | Значение |
|----------|----------|
| **Где хранится сессия** | Только в **`sessionStorage`** вкладки браузера. **Никогда в `localStorage`** и **Никогда в cookie** — это важно для безопасности. |
| **Время жизни (TTL)** | **1440 минут (24 часа)**. Константа `SESSION_TTL_MS` в [app.js](../app.js). |
| **Watcher** | Каждые **30 секунд** фоновый таймер проверяет: если текущее время > `session.expiresAt` → **мгновенный разлогин** и возврат на главную страницу с предупреждением «Сессия истекла». |
| **Когда сессия умирает сама** | Закрытие вкладки / закрытие браузера. |

> 🔐 **Почему sessionStorage?**  
> Если пользователь закроет вкладку — токен сам исчезает. Даже если кто-то украдёт пароль UI — он не получит доступ к WRITE токену (вводится отдельно).

## 3. Интерфейс админпанели

После успешного входа над главной таблицей появляется **жёлтая полоса админрежима**:

```
🟡 ВЫ В РЕЖИМЕ АДМИНИСТРАТОРА  ·  Сессия до 2026-09-30 21:45  ·  [Выйти]
[📥 Импорт JSON]   [📤 Экспорт JSON]   [💾 Сохранить все правки]
```

---

### 3.1 Модерация крана (1 строка = 1 кран)

Каждая строка в таблице получает **дополнительные редактируемые поля**:

| Поле | Тип | Назначение | Влияет на |
|------|-----|-----------|-----------|
| **✅ Вкл / ❌ Выкл** | чекбокс | Выключить кран из рейтинга (`is_enabled=0`). Выключенные краны либо скрыты, либо идут в самый низ с меткой `OFF`. | Финальный рейтинг (выключенный кран = рейтинг 0/F). |
| **Возраст (мес)** | число | `age_months` — возраст сайта в месяцах от даты регистрации. | **Блок 2 (Надёжность)**. Старше → больше баллов. |
| **Тип выплаты** | выпадающий список | `Auto` / `Manual` / `Mixed` | **Блок 2**. Auto = макс баллы, Mixed = средние, Manual = мин баллы. |
| **Шлюзов** | целое число | `gateways_count` — количество активных платёжных шлюзов (FaucetPay / Payeer / Crypto etc.) | **Блок 2**. >10 шлюзов → макс баллы. |
| **UII (0–100)** | число | **User Index Indicator** (0–100). Модератор выставляет субъективно: удобство интерфейса, дизайн, поддержка, частота жалоб. | **Блок 3**. Макс вес 20%. |
| **Bonus pts** | число (-∞..+∞) | Бонусные баллы. Положительные — поощрения за честность/долгую работу. Отрицательные — штрафы за накрутку/скам. | **Блок 4**. Макс вес 2%. |
| **Метка** | выпадающий список | `LEGIT` / `SCAM` / `NEW` / `МОЙ` / `—`. | Только визуально (не влияет на формулу). Метка `SCAM` автоматически добавляет красный фон строке. |

### 3.2 Импорт / Экспорт конфига модерации

| Кнопка | Что делает |
|--------|-----------|
| **`📤 Экспорт JSON`** | Скачивает весь `targets_moderation` из БД в одном файле `moderation_YYYY-MM-DD_HHmm.json`. **Бэкап**, который можно положить в облако. |
| **`📥 Импорт JSON`** | Загрузить файл экспорта → все таргеты модерации **ПЕРЕЗАПИСЫВАЮТСЯ** в `targets_moderation`. Действие не обратимо! |

### 3.3 Сохранение правок

| Способ | Действие |
|--------|----------|
| **`💾 Сохранить все правки`** | Отправляет накопленный батч всех `UPSERT` в `targets_moderation` за один Turso-запрос. Показывает модалку «Сохранено (58 строк)». |
| **Autosave** | НЕТ. Все несохранённые правки теряются при закрытии вкладки. Рекомендуется сохранять каждые 15 мин. |

## 4. Меню «Сырые данные / История» (админка)

│  2026-09-25   $18,204.10      $803.75     482             100   │
│  2026-09-26   $17,905.45      $606.72     455             98    │

## 5. Как сменить пароль UI-админпанели

Отредактируйте файл [auth_config.js](../auth_config.js):

```js
// auth_config.js
export default {
  // ⚠️ ТОЛЬКО UI-level защита. В реальной сети скрипт auth_config.js виден всем.
  // Реальная защита записи обеспечивается WRITE-READ токеном Turso.
  adminPassword: 'admin123', // <— замените на свой
};
```

> ⚠️ **Важно**: `auth_config.js` — публичный файл (отдаётся браузеру). Пароль из него **не обеспечивает безопасность БД**, он только
> скрывает сложные поля редактирования от случайного пользователя. Реальную защиту
> записи всегда обеспечивает **WRITE-READ токен Turso**.
