# FaucetPay Monitor — дашборд для криптовалютных кранов

Статический GitHub Pages дашборд, который каждый час (GitHub Actions cron) собирает данные о всех доступных кранах FaucetPay, сохраняет историю в edge-БД Turso, рассчитывает показатели «Здоровье» (Health Score) и «Рейтинг» кранов с многоуровневой системой защиты от накрутки показателей, и отображает всё в удобной таблице с сортировкой, фильтрацией, поиском и пагинацией. Администратор может через встроенную панель модерировать UII (User Interest Index), блокировать/поднимать краны и подкручивать веса рейтинга «на лету» без деплоя.

### 🔒 Важные правила

- Файл `Turso_DB_Connection.md` (локальный, с WRITE-READ токеном) **НИКОГДА НЕ КОММИТИТЬСЯ** в репозиторий.
- В коде публикуется **только READ-ONLY токен** Turso. WRITE-READ живёт исключительно в GitHub Secrets (`TURSO_TOKEN`) и в локальном `Turso_DB_Connection.md`.
- При любом изменении критической логики в `app.js` **обязательно**: (1) инкрементировать `CACHE_KEY` в IndexedDB (например `real-v3` → `real-v4`), (2) инкрементировать cache-buster `app.js?v=N` в `index.html`.
- Любая правка формул рейтинга/здоровья в `app.js` **ОБЯЗАТЕЛЬНО** дублируется в `healthScore.js` и `ratingCalculator.js` (принцип симметрии клиент/сервер пайплайна).
