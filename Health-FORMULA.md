1. Берём все пиковые значения балансов по каждой монете за 7 дней - и выбираем медианное значение. Это и будет эталонным значением для этой монеты.
2. Сравниваем среднее значение от [текущее + два предыдущих] с эталонным значением по монете - получаем в итоге процент здоровья по этой конкретной монете.
3. Высчитываем вес монеты следующим образом: берём медианное значение за семь дней (в долларах) и делим на сумму медианных значений (в долларах) всех учавствующих в расчёте монет - получаем удельный вес монеты в процентах.
4. Умножаем полученный процент здоровья по монете на процент её веса и делим на 100.
5. Суммируем все полученные (по пунктах 1-4) показатели (в процентах) по каждой монете и получаем итоговый Health Score.

Описание логики в виде кода:

def calculate_health_score(coins_data: dict, prices: dict) -> float:
    """
    Расчёт итогового Health Score крана на основе медианы за 7 дней
    и скользящего среднего за последние 3 замера.

    coins_data = {
        'BTC': {
            'daily_peaks': [0.001, 0.0012, 0.0009, 0.001, 0.0011, 0.001, 0.001],
            'recent_balances': [0.001, 0.001, 0.00095]
        },
        ...
    }
    prices = {'BTC': 60000.0, 'DOGE': 0.10, ...}
    """
    coin_metrics = {}
    total_usd_median = 0.0

    # Шаг 1-3: Сбор медиан, скользящих средних и долларов
    for coin, data in coins_data.items():
        daily_peaks = data.get('daily_peaks', [])
        recent_balances = data.get('recent_balances', [])
        price = prices.get(coin, 0.0)

        # 1. Медианное значение за 7 дней
        median_val = statistics.median(daily_peaks) if daily_peaks else 0.0

        # 2. Скользящее среднее (по последним зафиксированным точкам, до 3-х)
        ma_val = sum(recent_balances) / len(recent_balances) if recent_balances else 0.0

        # 3. Процент здоровья монеты (с капом в 100%)
        if median_val > 0:
            health_pct = min(100.0, (ma_val / median_val) * 100.0)
        else:
            health_pct = 0.0

        # 4. Перевод эталонной медианы в USD
        median_usd = median_val * price
        total_usd_median += median_usd

        coin_metrics[coin] = {
            'health_pct': health_pct,
            'median_usd': median_usd
        }

    # Шаг 4-5: Расчёт весов и итогового балла
    if total_usd_median <= 0:
        return 0.0

    total_score = 0.0
    for coin, metrics in coin_metrics.items():
        weight_pct = (metrics['median_usd'] / total_usd_median) * 100.0
        total_score += (metrics['health_pct'] * weight_pct) / 100.0

    return round(total_score, 2)

# ==============================================================================
#
# 1. ДЕЛЕНИЕ НА НОЛЬ И ПУСТЫЕ БАЛАНСЫ (median_val == 0)
#    - Проблема: Кран был пуст все 7 дней, либо монета только добавлена.
#    - Решение: Если median_val == 0, health_pct принудительно ставится в 0.0.
#      Монета получат 0% здоровья и 0% вес в общей финансовой структуре.
#
# 2. НУЛЕВОЙ ОБЩИЙ КАПИТАЛ СЕЙЧАС (total_usd_median == 0)
#    - Проблема: На всех монетах медианы равны 0 или отсутствуют цены.
#    - Решение: Возвращаем 0.0 вместо падения с ZeroDivisionError при делении на total_usd_median.
#
# 3. ПЕРЕПОЛНЕНИЕ БАЛАНСА (ma_val > median_val)
#    - Проблема: Админ закинул $1000 при норме в $10, отчего ma_val / median_val = 100 (10000%).
#    - Решение: Ограничение min(100.0, ...). Здоровье одной монеты не может превышать 100%,
#      иначе сверхбаланс одной монеты искусственно перекроет проблемы всех остальных.
#
# 4. НЕДОСТАТОЧНО ТОЧЕК ДЛЯ СКОЛЬЗЯЩЕГО СРЕДНЕГО (len(recent_balances) < 3)
#    - Проблема: База только начала собираться или были сбои API.
#    - Решение: Использовать len(recent_balances) в знаменателе вместо жесткого деления на 3.
#      Если массив пуст, берется 0.0.
#
# 5. ОТСУТСТВИЕ ИЛИ НЕДЕЙСТВИТЕЛЬНОСТЬ КУРСА МОНЕТЫ (price <= 0 или None)
#    - Проблема: API курсов валют вернул None / 0 или новая редкая монета отсутствует в справочнике.
#    - Решение: .get(coin, 0.0) предотвращает KeyError, а нулевой курс исключает монету
